# Data Format — dawud.json

```json
{
  "metadata": {
    "id": 1, "length": 5274,
    "arabic":  { "title": "سنن أبي داود", "author": "الإمام أبو داود سليمان بن الأشعث" },
    "english": { "title": "Sunan Abi Dawud", "author": "Imam Abu Dawud Sulayman ibn al-Ash'ath" }
  },
  "chapters": [ { "id": 1, "arabic": "...", "english": "Purification" } ],
  "hadiths": [
    { "id": 1, "chapterId": 1, "arabic": "...", "english": { "narrator": "...", "text": "..." } }
  ]
}
```

`data/chapters/` is generated by `node scripts/build.mjs`. Do not edit manually.
