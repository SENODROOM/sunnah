# CLI Reference — sunan-abi-dawud

```
dawud <hadithId>
dawud <chapterId> <hadithId>
dawud --search "<query>" [--all]
dawud --chapter <id>
dawud --random
dawud --react
dawud --version
dawud --help
```

## Language flags
- (default) — English only
- `-a` / `--arabic` — Arabic only
- `-b` / `--both` — Arabic + English
